First-time setup

  1. Start the CodeSync backend and open its portal; connect GitHub and copy the one-time API token.
  2. Paste the token under Connection below and press Test connection.
  3. Pick a repository under Repository, choose your platforms, then press Save settings.
  4. Submit a solution on LeetCode / GeeksforGeeks / CodeChef — it is detected automatically and lands in your GitHub repository.

Nothing to configure on the site itself: once the four steps above are done, just solve and submit as usual.
